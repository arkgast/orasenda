## Contract
- **B1b: `Lane`.** The same shape in both crates: `crates/store` `tasks::Lane` and `crates/service` `api::Lane`.
  - `pub struct Lane(Cow<'static, str>)` (`Clone, Debug, PartialEq, Eq, Hash`; not `Copy`).
  - `pub const BACKLOG: Lane = Lane(Cow::Borrowed("backlog"))`, and likewise `TODAY`, `DOING` and `DONE`.
  - `pub fn parse(s: &str) -> Option<Lane>`: a built-in, or `c_` followed by 8 of `[0-9a-z]`.
  - `pub fn as_str(&self) -> &str`; `pub fn builtin(&self) -> Option<Builtin>`.
  - `pub enum Builtin { Backlog, Today, Doing, Done }`: `Copy`, for `match`.
  - The consts are compared with `==` or matched through `builtin()`; they are never used as patterns.
  - `columns.rs`' `LANES` array becomes `fn builtins() -> [Lane; 4]`.
  - `api::Lane` validates its shape on deserialize: `#[serde(try_from = "String", into = "String")]`, with `#[specta(type = String)]` so TS sees `string`.
  - Whether a lane exists on this board is the service's check (B2a and B2b), not serde's.
  - Until B2a lands, the service refuses any non-built-in lane on `task_add` and `task_move` with the existing `BoardError::BadColumns`.
- **B1b: store reads.** `tasks::count_live_in(txn: &Txn, lane: &Lane) -> Result<u32, StoreError>` and `tasks::lanes_live(txn: &Txn) -> Result<Vec<Lane>, StoreError>`.
- **B2a: column types.** `ColumnSettings { lane: Lane, name: String, limit: Option<u8>, #[serde(default)] order: u8, #[serde(default)] folded: Option<bool> }`. `folded: None` reads as the default: Done folded, the rest open. `ColumnView` gains `custom: bool, folded: bool`.
- **B2a: commands** (Tauri and TS `commands.*`):
  - `board_column_edit(lane: Lane, name: String, limit: Option<u8>) -> Result<(), BoardError>`
  - `board_column_add(after: Lane) -> Result<Lane, BoardError>`
  - `board_column_remove(lane: Lane) -> Result<(), BoardError>`
  - `board_column_fold(lane: Lane, folded: bool) -> Result<(), BoardError>`
  - `board_columns_set` is removed.
- **B2a: errors.** `BoardError` gains `TooManyColumns`, `ColumnNotEmpty`, `ColumnNotFound`, `BadColumnName` and `BadLimit`.
- **B2a: words and hook.**
  - `apps/orasenda/src/features/board/boardWords.ts` exports `boardWords(error: BoardError | "unreachable"): string`:
    - `TooManyColumns`: "Up to 4 extra columns."
    - `ColumnNotEmpty`: "Move its tasks out first."
    - `ColumnNotFound`: "That column is gone. Pick another."
    - `BadColumnName`: "Another column has that name."
    - `BadLimit`: "That limit isn't allowed here."
    - `notFound`: "That task is gone."
    - anything else: "That didn't save. Try again."
  - `useBoardActions.ts` and `detail/useTaskDraft.ts` use it.
  - `useBoard()` returns `editColumn(lane, name, limit)`, `addColumn(after): Promise<Lane | null>`, `removeColumn(lane)` and `foldColumn(lane, folded)`; `setColumns` is removed.
- **B3: `ScrollRegion`.** `ScrollRegionProps.axis?: "y" | "x"` (default `"y"`), in both `scroll-region.tsx` and `src/types.ts`.
- **B4a: `KanbanColumn`.**
  - `KanbanColumnProps` gains `onAdd?: () => void`, `onEdit?: () => void`, `editor?: ReactNode` and `addLabel?: string` (default "Add task to <title>").
  - `action` is removed; only `kanban-column.test.tsx:111` uses it.
  - The three header controls get data slots: `kanban-column-name`, `kanban-column-add` and `kanban-column-fold`.
- **B4b: `ColumnEditor`.** `packages/ui/src/components/ui/column-editor.tsx`, exported from `@orasenda/ui`. The root carries `data-slot="column-editor"`. `ColumnEditorProps`:
  - `name: string`
  - `limit: { value: number; min: number; max: number; zeroLabel?: string } | null`
  - `error?: string`
  - `taken: readonly string[]` (the other columns' names)
  - `canAdd: true | { reason: string }`
  - `canRemove: true | { reason: string } | null`
  - `onSave(v: { name: string; limit: number | null }): void`
  - `onCancel(): void`, `onAdd(): void`, `onRemove(): void`
- **B5: TaskPicker.** `TaskPickerOption.order: number` replaces the fixed `lane: "doing" | "today" | "backlog"`. `hint` stays the column's name.

  - the Board, Today, palette and Inbox vitest suites;
