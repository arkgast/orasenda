Every task writes its tests first, keeps every file ≤ 500 lines, passes `./scripts/ci.sh`, and gets an opus review plus one fix round. UI tasks also get the opus design review (layout boxes and gaps, both themes, keyboard, VoiceOver names); no screenshots, the owner reviews visuals.

IPC tasks regenerate `bindings.ts` (`just bindings`) and never hand-merge it. Append-only registration files keep both sides on conflict: `commands/mod.rs`, `lib.rs`, `build.rs`, `capabilities/main.json`, `lib_tests.rs`, `ipc.rs`, `shared/test/fixtures*`, `designSystem.test.ts`, the `Host` trait and its fakes, icon lists, common issues.

## Contract
- **B2 owns** `orasenda_core::rank::{between, before, after}` and `task_id: Option<String>` on `SessionRecord`, the live session and `open_focus`, plus `Engine::set_task`.
- **B3 owns** `orasenda_store::tasks` (`NewTask`, `TaskRow`, `TaskPatch`, `Lane`, `Priority`, `TaskKind`, `ChecklistItem`, the functions in the spec) and `Entity::Task`.
- **B8 owns** the board IPC: `BoardView`, `ColumnView`, `LimitState`, `TaskView`, `TaskDraft`, `TaskPatchView`, `BoardError`, every board command, `board-changed` (`{seq, board}`) and `Host::emit_board_changed`, and `Settings.board.estimate_buffer`.
- **B9 owns** `StartRequest.taskId`, `timer_set_task`, `TimerView.task: Option<TimerTask>`, `StartError::TaskNotFound` / `TaskDone`.
- **B4–B6 own** their components' props (READMEs are the contract).
- Screens (B10–B13) consume these and never change them; a needed change goes back to the owner as a ruling on its issue.

## Impact
- **Schema (B3):** a new table and `ALTER TABLE focus_session ADD COLUMN task_id`. Forward-only (ADR-012). Rollback is the backup the app already takes before a migration. Every store test and the fresh-schema table count must stay green. Routines landed 0007; if another migration lands first, the second renumbers.
- **Session engine (B2, B9):** the active-session snapshot gains a field (serde default; a v7 snapshot test). Every start path (`session/service.rs` Space toggle, `session/actions.rs` roll-on, tray `menu/commands.rs`, floater keys) goes through the service's next-task rule; their existing tests stay green.
- **Navigation (B1):** every page list changes at once; the Routines session must not touch them.
- **Portability (B7):** export, import (merge and replace) and backups of a v8 file; older exports still import.
