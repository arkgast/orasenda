The jump list beside the Settings content, from 640 × 480 up.

- **Anatomy:** an `index-width` column of 52px (`control-lg`) items, each the section name (`body`) and its current value (`body-sm` `ink-muted`).
- **Sections:** General, Timer, Notifications, Keyboard, Apps and sites, Privacy (only once tracking ships), About and data.
- **States:** current: `selection` ground, a `focus` side bar and `aria-current="location"`. A problem is said in words ("Not saved", "Check focus minutes"); the alert glyph appears only for a problem no save-line event announces (a shortcut conflict: "Pick a new shortcut").
- **Keyboard:** one roving tab stop; ↑/↓ move; Return jumps to the section and focuses its heading.
- **Compact:** replaced by a "Jump to section" `IconButton` that opens a native menu.

Do: say a problem in words. Don't: use colour or the glyph alone for a problem.
