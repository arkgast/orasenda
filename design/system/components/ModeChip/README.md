A shape and a word for a mode. It is a label, never a control.

- `mode`: `focus` (circle), `break` (half circle), `routine` (rounded square), `warning` (triangle), `shallow` (hollow circle, no hue), `paused` (bars), `idle` (hollow circle, "No session").
- `children` replaces the default word when a more specific one keeps the meaning ("Deep", "At limit").

Do: pair it with the matching tint so the colour is never the only signal. Don't: attach a click handler; for exclusive choices use native radios with 44px labels (see `CapturePad`).
