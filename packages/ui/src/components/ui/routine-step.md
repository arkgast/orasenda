The run view's body: one step at a time, with the whole run listed below in shape and word.

- **Anatomy:** a `section` named by its `h1` (the routine's name, `title`), the `progressLine` under it ("Step 2 of 5", `body-sm` `ink-muted`), the step body (the step name as an `h2` in `heading`, an *Optional* tag in `label` `routine` when `step.optional`, then each `detail` line in `body` `ink-muted`), the `actions` slot, and the progress list: an `ol` named "Steps". The section is at most `content-width` wide.
- **Props:** `routineName`, `progressLine`, `step { name, detail?: string[], optional? }`, `steps[]` (`{ name, state }` with `state` one of `upcoming | done | skipped`), `current` (the index of the step on screen; defaults to the first upcoming step), `actions` (the host's buttons), `finished`, `finishedLine`, `stepNameRef`, `className`. Slots: `routine-step`, `routine-step-progress`, `routine-step-body`, `routine-step-name`, `routine-step-detail`, `routine-step-actions`, `routine-step-list`, `routine-step-mark` (with `data-state`), `routine-step-state`, `routine-step-finished`.
- **Progress list, state as shape and word:** done is a filled `break` disc with an `on-break` tick and the word "Done"; skipped is a hollow `line-strong` ring with a dash and "Skipped"; the current step is a `focus` ring around a `focus` dot, the word "Now", bold `ink` text and `aria-current="step"`; upcoming is a dotted `line-strong` ring and "Upcoming". Marks are `icon-lg` and `aria-hidden`; each item reads "Get outdoor light, Now". Other rows are `ink-muted`.
- **Focus:** the step name has `tabIndex={-1}`: it is the focus target, never a tab stop. The component never moves focus itself; the host moves it to the step name after each answer (through `stepNameRef` or the slot), and to **Back to routines** when finished. The focus ring is the system 2px `focus-ring`.
- **Finished:** `finished` replaces the step body with `finishedLine` ("Routine finished. 4 of 5 done today.") beside a done mark, in `heading`. No step is current; the list stays as the run's record.
- **Motion:** each new step mounts a fresh body that fades in over `duration-calm` on `easing-calm` (from its `@starting-style`), so the change reads as a soft cross-fade. Under reduced motion it changes at once.
- **Host provides:** the buttons in `actions` (**Done** primary with Enter, **Skip for today** with S, **End routine** with Esc, honouring `keys.single_key`), the keyboard handling, the one polite live region that says the new step, and every line of copy (Rust words them).
- **Copy:** never "missed", "failed", "broken" or "streak lost"; a skipped step is "Skipped".

Do: keep one primary action in `actions`. Don't: put checkboxes in the run view; the progress list is a record, not a control.
