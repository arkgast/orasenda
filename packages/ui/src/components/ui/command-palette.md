The ⌘K palette: a search field over a list of commands.

- `commands`: `{ id, label, hint?, shortcut? }`. `shortcut` is a right-aligned `Kbd`; `hint` stays a second line. The first result is always the available start command; during a session Pause and End come first. `onSelect(id)` runs before `onClose`. Mount a fresh instance per invocation so the query starts empty.
- The field is a combobox with `aria-activedescendant`; Arrow Up and Down wrap through the results, Enter runs the highlighted command, Tab reaches Close, Escape closes. Keys pressed while an input method is composing are ignored. Moving the pointer over a row does not move the highlight, Ctrl+J/K/N/P do not move it, and Home and End move the caret in the field.
- Native modal on `surface-overlay` with a clear backdrop.
- Compact variant: `compact` is a prop the host sets below `layout-compact-height`. The title and label are visually hidden (still the dialog's and the field's names), the panel tightens its padding, and a Close `IconButton` sits beside the field instead of the Close button below the list. At 360 × 240 the list scrolls inside the panel.

Do: open it only when no other modal is open. Don't: list commands that are unavailable right now.

Implementation: a Radix Dialog (role `dialog`, not a native `dialog`) holding a `cmdk` list with `shouldFilter` off, so the filter stays the substring match on label and hint. The panel carries `data-slot="dialog-content"` so layers and Escape treat it like a Dialog. The highlighted row also shows the word "Selected". `Command.shortcut` is one canonical glyph string; the row draws it as a `Kbd` on the right and passes `spoken` from `describeShortcut`, so the spoken form ("Control-Option-F") is part of the row's name. A long label and hint wrap at the row's left; the `Kbd` never wraps and is never hidden. The list stays one tab stop: the search field owns focus (`aria-activedescendant`), and Close is the only other stop. The compact Close mark is interim and becomes `Icon` in T7.
