Records one keyboard shortcut, in Orasenda or from anywhere. The host labels each slot.

- **Anatomy:** the row `label` above a field-like `button` on `surface-sunken` with a `line-strong` border, at least `field-width` wide (never wider than `panel-width`); the keys in mono (`aria-hidden`) plus a hidden span with the keys in words; the visible hint "Change". A message line (always present and two lines tall, so the row keeps its height when the warning question or the message wraps at the Shortcuts pane's column; `text-body-sm`, `ink`) sits above the helper line. A helper line below says what a shortcut needs, and an optional ghost button "Restore default" shows only when `onRestoreDefault` is set, so a row that owns one Restore default for both of its recorders omits it on each.
- **Props:** `label`, `accessibleName` (what a screen reader hears in place of `label` when slots share a visible label, for example "Full screen, In Orasenda"; the visible label is unchanged), `keys` (a canonical glyph string; omit it for an empty slot, shown as `emptyLabel`, "None" by default), `spokenKeys` (defaults to `describeShortcut(keys).spoken`), `recording` (starts the field recording), `conflict` (the host's line), `emptyLabel` (the word for an empty slot, spoken too), `warning` (`{ reason, onUseAnyway, onPickAnother }`: a well-known key the host wants confirmed), `appOnly` (the In Orasenda slot: only ⌘ or ⌃ count, ⌥ alone does not; the helper reads "Command or Control" and the message "Add ⌘ or ⌃. A single key can't be a shortcut."), `onRecord(keys | null)`, `onRestoreDefault`, `onRecordingChange(on)` (true when recording starts; false once when it ends by a record, Esc, blur or unmount, sent before `onRecord`, so the host can suspend its shortcuts meanwhile), `id` (lands on the button).
- **States:** rest; recording (`selection` ground, `focus` border, hint "Type keys, Esc cancels", kept on one line so the field keeps its height); conflict (a `line-strong` inset ring plus an alert-glyph line, for example "Orasenda uses ⌘K for Commands. Pick a different one."); message (a plain key with no ⌘, ⌃ or ⌥ shows one polite line in the reserved row, "recording continues"; it fits two lines at the Shortcuts pane's column); off (the field reads "None").
- **Warning:** with `warning` set, the always-present polite message row reads "<reason> Use it everywhere anyway?" (a region that stays mounted, so VoiceOver announces the change), with two buttons below it: "Pick another" (`quiet`) first in focus order and holding initial focus, then "Use anyway" (`ghost`); both are described by the question (`aria-describedby` on the message row). Pick another calls `onPickAnother` and returns focus to the field; Use anyway calls `onUseAnyway` and returns focus to the field too, since the host removes the buttons. The recorder sends nothing itself.
- **Keyboard:** Return, Space or a click starts recording; Esc cancels; Delete alone calls `onRecord(null)` (off); a press with ⌘, ⌃ or ⌥ plus a key calls `onRecord` with its canonical glyph string and ends recording. A modifier pressed alone and an unknown key record nothing and recording continues. A key without ⌘, ⌃ or ⌥ records nothing, says "Add ⌘, ⌃ or ⌥. A single key can't be a shortcut." in the message line, and recording continues. Tab and Shift-Tab leave the field and end recording. A click also focuses the field (WebKit doesn't focus a clicked button), so the keys reach it and only one recorder records at a time: starting one blurs, and so ends, any other.
- **Output:** it reads `KeyboardEvent.code` (so Option-F is still F) and the modifiers, and emits the key table's form in `⌃⌥⇧⌘` order: `⌃⌥F`, `⇧⌘P`, `⌘.`. Every string it can emit round-trips through `describeShortcut`. Keys: A to Z, 0 to 9, Period, Comma, Return, Space, Tab, Delete (⌫, with a modifier) and the arrows.
- **Decisions stay with the host:** the recorder never decides whether a binding is allowed. The host passes `conflict` (Rust decides) and may pass a new `keys`.
- **VoiceOver:** no `aria-label` and no `aria-invalid`. The name comes from `aria-labelledby`: label (or `accessibleName` when given) + spoken keys + hint ("Start or pause focus from anywhere, Control-Option-F, Change"). The conflict line, the message line (which carries the warning question) and the helper are linked with `aria-describedby`. Only the message line is live (`aria-live="polite"`); the conflict line is not.

Do: name the clash and what to do. Don't: accept a single letter without a modifier.

**In a 3A row:** two recorders sit side by side (In Orasenda, Everywhere), each at about 236 wide; the host lays them out with `grid-cols-2` and a `space-4` gap. Below 2 x `field-width` + `space-4` (456) the field would overflow its column, so the host stacks the recorders instead. At 236, Pick another and Use anyway stack (they need about 276 side by side). The "VoiceOver uses this key while it's on. Pick another to use both." line is the host's `conflict`; "Not available" (a failed registration) is the row's own status word, not recorder copy.
