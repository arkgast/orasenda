The persistent disclaimer next to wellness content.

- Default copy: "Wellness suggestion, not medical advice." Pass `children` for a more specific note, for example that evidence is limited.
- `as: 'p'` for a standalone note at the foot of a routine; the default `span` sits inline.
- It has `role="note"` and a decorative glyph in `ink-muted`.

Do: place it beside every routine template, NSDR and sound option. Don't: reword it into a claim of benefit.
